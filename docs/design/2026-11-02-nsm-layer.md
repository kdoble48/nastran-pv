# Nonstructural mass layer

Status: approved plan (2026-11-02); details decided during implementation.

## Goal

Show where the nonstructural mass (NSM) of a model sits and how much there is, from both sources:
the NSM field of the property cards and the bulk `NSM`, `NSM1`, `NSML`, `NSML1` sets combined by
`NSMADD`. Before this change the property NSM was hidden inside the shells' `MassPerArea`, line
NSM was ignored and the bulk cards were not read, so `ModelMass` was short by the bulk NSM.

Deliverables: per-element arrays, root totals and tables, an `nsm` view and *NPV NSM* macro, and
`--nsm-set` on `convert`/`stats`/`store`/`view`/`render` (reader property *NSMSet*).

## Decisions

1. **`ElementMass` is structural + NSM**, as in Nastran. `MassPerArea` becomes structural only
   (`MassPerArea_structure()`), lines gain their property NSM, and `StructuralMass` excludes NSM.
   New root scalar `NonstructuralMass`; `ModelMass` = structural + nonstructural + concentrated.
2. **Arrays** on Shells and Lines only: `NSMPerArea` (shells) and `NSMPerLength` (lines), separate
   names because the units differ (separate color maps); `NSMMass`; `NSMSource` (0 none,
   1 property, 2 bulk, 3 both). They are written only when some element gets NSM, so decks without
   NSM (or whose selected set matches nothing) keep their arrays unchanged.
3. **Rules** (MSC QRG; pyNastran's `mass_properties_nsm` as the reference, not called, because it
   only gives totals): `NSM`/`NSM1` are per unit area or length; `NSML`/`NSML1` are a total spread
   by area or length (`NSML` per id, `NSML1` over the whole id list). TYPE matches the property
   card exactly (`PSHELL` does not cover PCOMP; `PBAR` does not cover PBARL). `ELEMENT` takes EIDs
   of elements whose property takes NSM (CVISC, CBEND, ... warn and are skipped), `ALL` every
   element of that type. PBEAM's per-station NSM is averaged.
4. **NSMADD** is resolved recursively. A cycle and a leaf reached twice warn; the leaf counts once.
   Totals are kept per leaf set.
5. **Which set applies:** `--nsm-set ID` (0 = none), else Case Control `NSM=` (the first, with a
   warning when subcases differ), else in a bulk-only file the single top-level set (with a
   warning). A run deck without `NSM=` applies none, as Nastran does, and warns. The property NSM
   always applies. Root `ActiveNSMSet` records the choice (-1 = none).
6. **Root tables:** `NSM_SET NSM_SetType NSM_SetMass NSM_SetCount` per leaf set and
   `NSM_PID NSM_PIDMass`, plus `PropertyNSMMass` and `BulkNSMMass`.
7. **Bad input never raises:** unsupported types (PBEND, PCONEAX, PRAC2D, PBCOMP), unknown ids,
   `NSML` over both shells and lines, and zero-size targets warn and skip. These warnings, and
   "model mass excludes ...", are mass warnings (`Deck.warn(..., mass=True)`): they come first in
   `Deck.warnings`, so the CLI's and the reader's shortened lists still show them.
8. **No density:** an element without thickness, area or density keeps its NSM; `StructuralMass`
   is summed from the finite structural parts, so it never goes negative.

## Code

`src/nastran_pv/nsm.py` (selection, NSMADD, distribution, root arrays) runs in `build_multiblock`
after the mesh blocks are built and before the masses; `massprops.element_mass` adds `NSMMass`.
The view is `nastran_views.view_nsm`. Tests: `tests/data/nsm.bdf` (hand-computed values in its
header), `tests/test_nsm.py`, the NSM edge cases in `test_robustness.py`, and `pv_smoke.py`.
The gallery shows `nsm` on the demo tray (`docs/models/make_demo.py`: PSHELL paint, an NSM1
harness strip and an NSML1 cable bundle). MYSTRAN applies only the PSHELL NSM, so the demo's
solved modes leave the bulk sets out.

## Not done

- NSM on CQUAD/CTRIA elements' own fields, PBUSH and solids (no NSM in Nastran), and `NSMADD`
  scale factors (not part of the card) are out of scope.
